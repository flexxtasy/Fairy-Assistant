# sprites/

Everything here is generated by the scripts in the repo root:

    make_sprite.py  ->  sprites/base/fairy.png (one original donor composite)
    make_full.py    ->  full-body packs (motion variants of that base)
    make_anim.py    ->  ring-icon packs (smooth + pixel variants)

The base composite is built from your own copies of game-derived reference
images (set FAIRY_SRC_SPRITE / FAIRY_SRC_ANIM to your paths). The result is
fan-made derivative art of Zenless Zone Zero characters — trademarks of
HoYoverse. Code: MIT (root LICENSE). Art: fan content, check HoYoverse's
fan-content policy before any commercial use.
